# Chrono

Aplicación móvil para gestionar proyectos, tareas y registrar el tiempo dedicado a cada actividad.

  Estado del proyecto

Actualmente en desarrollo.

  Objetivo

Chrono busca proporcionar una forma sencilla de organizar actividades y llevar un registro del tiempo invertido en diferentes proyectos.
